# school-telegram-bot
a bot that saves student data into the database and can be recalled for it
## What you can do with it
-you can save data of a student
-Ask for the saved data
### How to use
-In the config file you need to put in your own telebot Token
-save data (typing in database, running main.py file, choose the 'I am teacher'(password:12345))
-choose any button you want(when is the next lesson?,what group am i in?,What day is the lesson?,what class do i have?)
